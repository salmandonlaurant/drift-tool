# Drift Tool — αυτόματα βαθμιδωτά διαγράμματα drift

Τοπική εφαρμογή για Windows που παίρνει πίνακα ορόφων + οριζόντιων μετακινήσεων
από το SAP2000, υπολογίζει το σχετικό drift κάθε ορόφου, φτιάχνει τις δύο βοηθητικές
στήλες της βαθμιδωτής γραμμής και σχεδιάζει πολλές καμπύλες πάνω στο ίδιο διάγραμμα
με γραμμή ορίου.

Δεν χρειάζεται σύνδεση με το SAP και δεν αλλάζει το μοντέλο. Αντιγράφετε τον πίνακα,
τον επικολλήτε, ελέγχετε και εξάγετε.

Η εφαρμογή έχει **ελληνικό και αγγλικό περιβάλλον** (κουμπί `EN / ΕΛ` πάνω δεξιά)·
η επιλογή επηρεάζει και τις ετικέτες των διαγραμμάτων και το Excel.

> **Νέοι χρήστες:** ξεκινήστε από τον αναλυτικό, απλό οδηγό
> **[GUIDE_GR.md](GUIDE_GR.md)** — εξηγεί βήμα-βήμα τι κάνει το πρόγραμμα, πώς
> γίνεται η επικόλληση, πώς διαβάζεται το διάγραμμα και τι σημαίνει κάθε
> προειδοποίηση.

## Γρήγορη εκκίνηση

1. Διπλό κλικ στο **`Drift Tool.bat`**.
   Την πρώτη φορά δημιουργεί αυτόματα περιβάλλον `.venv` και εγκαθιστά `flask` και
   `openpyxl` (χρειάζεται internet μία φορά). Μετά ανοίγει τον browser μόνο του.
2. Επικολλήστε τον πίνακα από το SAP στο πεδίο **«Επικόλληση δεδομένων από SAP2000»**
   και πατήστε **«Ανάλυση & εφαρμογή»**.
3. Ελέγξτε τον πίνακα ορόφων (τα ύψη, το όριο, τις υπερβάσεις).
4. Εξάγετε με **Excel / SVG / PNG / PDF**, ή αποθηκεύστε το έργο με **Αποθήκευση**.

Χειροκίνητη εκκίνηση από terminal:

```powershell
cd C:\Users\Admin\Projects\drift-tool
python -m pip install -r requirements.txt
python server.py
```

Η εφαρμογή ακούει μόνο σε `127.0.0.1` και ανοίγει σε ελεύθερη θύρα (ξεκινά από 8765).

## Μορφή δεδομένων εισόδου

Επικολλήστε **δύο ή τρεις στήλες**, με Tab, `;`, `|` ή κενά:

| Όροφος | u | h (προαιρετικό) |
|---|---|---|
| 0 | 0,0000 | — |
| 1 | 0,0042 | 4,2 |
| 2 | 0,0118 | 3,8 |

- Δεκαδικό **κόμμα ή τελεία** — αναγνωρίζονται και τα δύο.
- Οι μονάδες ορίζονται στην καμπύλη: `u` σε mm/cm/m/in, `h` σε m (συνήθως).
- Αν λείπει η στήλη `h`, τα ύψη συμπληρώνονται από τον **πίνακα υψών του μοντέλου**
  ή από το προεπιλεγμένο ύψος. Δεν αντικαθίστανται ποτέ με μηδέν.
- Η **γραμμή ορόφου 0 είναι υποχρεωτική** (ή δηλώνετε ρητά μετακίνηση βάσης στην
  καρτέλα «Μοντέλο / Ύψη»). Χωρίς βάση δεν υπολογίζεται drift.

## Κανόνες υπολογισμού

```
Δuᵢ = uᵢ − uᵢ₋₁            (η βάση αφαιρείται μόνο στον όροφο 1)
dᵢ  = |Δuᵢ| / hᵢ           hᵢ = ύψος από το επίπεδο i−1 έως το επίπεδο i
υπέρβαση: dᵢ > όριο        (αυστηρά μεγαλύτερο)
```

Βαθμιδωτή γραμμή, για κάθε όροφο i με σειρά ανόδου:

```
(dᵢ, i−1)  →  (dᵢ, i)
```

N όροφοι ⇒ **ακριβώς 2N σημεία**. Τα σημεία **δεν** ταξινομούνται κατά X και **δεν**
προστίθεται τεχνητό σημείο `(0,0)`.

Το όριο δέχεται ισοδύναμες μορφές:

| Γράφετε | Διαβάζεται |
|---|---|
| `0,002` ή `0.002` | 0,002 |
| `0,2%` | 0,002 |
| `1/500` ή `1:500` | 0,002 |

Προσοχή: το σκέτο `0,2` **δεν** θεωρείται 0,2% — παραμένει 0,2.

## Τι σημαίνουν οι προειδοποιήσεις

| Μήνυμα | Σημασία |
|---|---|
| `NO_BASE` | Λείπει όροφος 0 και δεν έχει επιβεβαιωθεί μετακίνηση βάσης — δεν σχεδιάζεται drift. |
| `GAP` | Μη διαδοχικός όροφος. Το κενό **δεν** γεφυρώνεται· η καμπύλη σπάει. |
| `DUP_FLOOR` | Διπλός όροφος — κρατείται η πρώτη γραμμή. |
| `MISSING_U` | Κενή/μη αριθμητική μετακίνηση — η γραμμή δεν υπολογίζεται. |
| `MISSING_H` / `BAD_H` | Λείπει ή δεν είναι θετικό το ύψος — η γραμμή δεν υπολογίζεται. |
| `UNSORTED` | Οι γραμμές ταξινομήθηκαν αυτόματα κατά όροφο. |

Καμία τιμή δεν αντικαθίσταται σιωπηλά με μηδέν. Ό,τι δεν υπολογίζεται, φαίνεται.

### Φασματική ανάλυση

Αν μια καμπύλη δηλωθεί ως **«Φασματική»**, η εφαρμογή εμφανίζει μόνιμη προειδοποίηση:
η απλή αφαίρεση συνδυασμένων μεγίστων ανά όροφο **δεν** δίνει έγκυρο φασματικό drift.
Χρειάζεται σχετική απόκριση (relative displacement) ή κατάλληλος modal συνδυασμός
από το SAP. Η ένδειξη περνά και στο Excel.

## Διαγράμματα, καμπύλες, εμφάνιση

- Αριστερά δημιουργείτε **πολλά ανεξάρτητα διαγράμματα** και **πολλές καμπύλες** ανά
  διάγραμμα (δοκιμασμένο με 7 διαγράμματα × 15 καμπύλες).
- Κάθε καμπύλη έχει όνομα, χρώμα, πάχος, στυλ γραμμής (συνεχής/διακεκομμένη/…),
  διεύθυνση, περίπτωση ανάλυσης και προέλευση.
- Το υπόμνημα ενημερώνεται μόνο του, μπαίνει έξω από την περιοχή σχεδίασης και
  αλλάζει σε δύο στήλες όταν οι καμπύλες είναι πολλές. Κλικ σε εγγραφή υπομνήματος
  κρύβει/εμφανίζει την καμπύλη.
- **Μέση καμπύλη** μόνο κατόπιν επιλογής: πρώτα drift ανά καμπύλη, μετά μέσος όρος
  ανά όροφο, τέλος βαθμιδωτές συντεταγμένες. Μην τη χρησιμοποιείτε για ανόμοιες
  περιπτώσεις (π.χ. άνεμο + σεισμό).
- Κατακόρυφος άξονας: **όροφος** (προεπιλογή) ή **υψόμετρο** (σωρευτικό άθροισμα υψών).
- Οριζόντιος άξονας: δείκτης `d` ή ποσοστό `%`.

## Εξαγωγές

| Κουμπί | Τι παράγει |
|---|---|
| **Excel** | Φύλλο «Σύνοψη» + ένα φύλλο ανά καμπύλη με εισόδους, ύψη, Δu, d, d%, υπερβάσεις και **τις δύο βοηθητικές στήλες** (X = drift, Y = επίπεδο) στη σειρά του εγγράφου. |
| **SVG** | Διανυσματικό σχήμα, ίδιο ακριβώς με την προεπισκόπηση. |
| **PNG** | Εικόνα 3× ανάλυσης (κατάλληλη για Word/PowerPoint). |
| **PDF** | Εκτύπωση σε A4 οριζόντια — «Αποθήκευση ως PDF» από τον διάλογο εκτύπωσης. |
| **Αποθήκευση / Άνοιγμα** | Πλήρες έργο σε `.drift.json`. Η εργασία αποθηκεύεται και αυτόματα στον browser. |

## Batch (χωρίς άνοιγμα εφαρμογής)

```powershell
# Από αποθηκευμένο έργο -> SVG + XLSX για κάθε διάγραμμα
python drift.py --project examples\demo.drift.json --out out\demo

# Από αρχείο πίνακα (Tab/CSV/κενά)
python drift.py --in examples\wind-cbs.tsv --limit 1/500 --units-u mm ^
                --default-h 4.0 --heights "1=4.2,2=3.8" --name "Wind X" ^
                --out out\wind

python drift.py --help
```

Το batch γράφει **SVG + XLSX** και τυπώνει στη κονσόλα τυχόν προβλήματα δεδομένων
(κενά, μη διαδοχικοί όροφοι, λείπουσα βάση). Το Excel περιέχει πάντα και τις βοηθητικές
στήλες, ώστε το διάγραμμα να μπορεί να ξαναφτιαχτεί και με το χέρι.

## Σημειώσεις

- Το `examples/demo.drift.json` περιέχει **συνθετικά** δεδομένα μόνο για επίδειξη της
  μορφής· δεν είναι μετρήσεις και δεν πρέπει να χρησιμοποιηθούν ως αναφορά.
- Τα δεδομένα μένουν στον υπολογιστή σας. Ο server δεν στέλνει τίποτα έξω.
- Αν η εφαρμογή δεν ανοίξει, δείτε το μήνυμα του `Drift Tool.bat` ή τρέξτε
  `python server.py` από terminal για να δείτε το σφάλμα.
